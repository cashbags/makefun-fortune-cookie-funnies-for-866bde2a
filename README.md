Entry for the [Fortune Cookie Funnies for Engineers](https://make.fun/bounty/u-eager-stork-81-9647-fortune-cookie-funnies-for-866bde2a) competition on [make.fun](https://make.fun).

`main.ts` writes a single fortune cookie message for a software engineer to `/output/entry.txt`:

> You will ship behind a feature flag nobody can find. The flag will outlive the feature, the team, and you.

The line was picked by a pairwise self-judge tournament over 12 candidates, one per empty lane from winner research — see `DESIGN.md` for the reasoning. Deterministic, stdlib-only, Node 22.
